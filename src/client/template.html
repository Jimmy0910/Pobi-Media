Pobi Media 透視校正與 PDF 操作手冊

關於 Pobi Media 專業工作站
Pobi Media 是一套高效率的純前端本機運算多媒體處理系統，專為照片文件拉平、梯形透視校正、高品質 JPG/PNG/WEBP 下載及多圖合併多頁 PDF 文件而設計。
核心優勢：
  • 極致隱私安全：影像處理 100% 在您的瀏覽器本機端透過 WebGL 與 HTML5 Canvas 完成，圖片不外流。
  • 跨裝置雲端帳號：支援電腦、平板與手機多裝置切換，帳號隨處登入。
  • 秒速生成 PDF：無須繁瑣中轉，校正完畢即刻一鍵輸出多頁 PDF 文件。

透視校正 3 步操作流程
  1. 匯入圖片：在左側面板點擊上傳或直接拖曳圖片至待處理清單中（支援多張批次匯入）。
  2. 拖曳拉平：在中央畫布拖曳四個角點（左上、右上、右下、左下）緊密貼合文件或照片的四個角落。
  3. 匯出下載：在右側面板設定輸出格式、品質與長邊限制，點擊下載影像或匯出 PDF。

匯出格式 / 按鈕說明適用場景
JPG 照片文件標準 JPEG 壓縮格式。適合一般文件翻拍、書本掃描、生活照片。

批次合併匯出為多頁 PDF將佇列中所有校正好的圖片依序組合成一份完整多頁 PDF 文件。多頁合約、論文、掃描書籍整本匯出。
